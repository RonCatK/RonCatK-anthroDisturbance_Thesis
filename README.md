# anthroDisturbance_Thesis: test suites for the anthropogenic disturbance modules

Release **v1.0.0**. Test suites (system, validation, sensitivity and uncertainty), runner and analysis
scripts, run ledgers and summary metrics for three SpaDES modules written in R:
`anthroDisturbance_DataPrep`, `potentialResourcesNT_DataPrep` and `anthroDisturbance_Generator`.

**What this repository is not.** The modules themselves are git submodules and are *not* part of the
archived source (GitHub and Zenodo source archives do not include submodule contents). Large input data,
model outputs and the 2025 working directories are not included either.

## The four suites

Every suite is driven by `workspace/runner.R <config.yaml>` (see `workspace/README.md` for the config
schema). Outputs go to `outputs/<suite>/<run_name>/rep_###/`, logs to `scratch/<suite>/<run_name>/rep_###.log`,
and one ledger row per replicate is appended to `outputs/traceability/suite_runs/<suite>_runs.csv`.

| Suite | What it does | Configs | Run | Ledger rows (distinct run × replicate) | Executed |
|---|---|---|---|---|---|
| System | Stress tests under extreme configurations | `workspace/system/config/` | `bash workspace/system/run_system.sh` | 4 (4) | 25 Dec 2025 |
| Validation | Simulated vs reference maps (BEAD), allocation and quantity disagreement | `workspace/adqd_validation/config/` | `Rscript workspace/runner.R <config>`, then `Rscript workspace/adqd_validation/run_adqd_metrics.R` | 40 (40) | 25 Dec 2025 |
| Sensitivity (Morris) | Morris elementary-effects screening | `workspace/sensitivity/` | `build_morris_design.R`, `bash workspace/sensitivity/run_morris.sh`, `finalize_morris_metrics.R` | 240 (240) | 24 Nov – 26 Dec 2025 |
| Uncertainty | Random and site-selection uncertainty analysis | `workspace/uncertainty/` | `build_ua_design.R`, `run_generated.sh`, `run_ua_base.sh`, `build_site_selection_design.R`, `run_site_selection.sh`, `finalize_ua_metrics.R` | **135 (82)** | 24 Nov – 26 Dec 2025 |

All ledger rows have status `success`. See each suite's `README.md` for options.

## Evidence in this repository

* `docs/traceability/evidence/suite_runs/*.csv`: the run ledgers (config, seed, timestamp, status, log path).
* `docs/traceability/evidence/metrics/*.csv`: summary metrics derived from the runs.
* `docs/traceability/evidence/logs/`: copies of per-run log files for 356 of the 366 ledgered runs, with the
  local absolute path of the working copy replaced by `<REPO>` (the only edit). `MANIFEST.csv` lists every
  ledger entry with its original modification time, checksums before and after the replacement, and the
  reason for each exclusion. See `docs/traceability/evidence/logs/README.md`.
* `workspace/sensitivity/config/generated/` (60 configs) and `workspace/uncertainty/config/generated/`
  (8 configs): the per-run configs the sensitivity and random uncertainty ledger rows refer to. Use these
  rather than `sa_runs.csv` / `morris_design_points.csv`, which describe an earlier, smaller Morris design.
* `docs/traceability/traceability_matrix.*`: requirements-to-evidence matrix (generated by
  `workspace/helpers/generate_traceability_matrix.R`; in the committed snapshot the unit-test entries read
  "missing" or "Not evaluated").

## Repository layout

`workspace/` suites, runner and helpers · `modules/` git submodules (empty in source archives) ·
`data/` manifests, small study-area and test fixtures · `docs/` Appendix A (ODD description),
Appendix B (traceability matrix), traceability evidence, notes · `renv.lock`, `Dockerfile` (R 4.5.2)
for the environment · `.github/` CI. See `docs/repo_structure.md`.

## Getting started

```bash
git clone --recurse-submodules https://github.com/RonCatK/RonCatK-anthroDisturbance_Thesis.git
cd RonCatK-anthroDisturbance_Thesis
git submodule update --init           # checks out the pinned module commits listed above
Rscript -e 'renv::restore()'
Rscript workspace/helpers/validate_runner_configs.R
Rscript workspace/helpers/prepare_data.R --profile=all     # fetch inputs (see data notes below)
bash workspace/run_end_to_end.sh                            # or run single configs with workspace/runner.R
```

When working from a downloaded source archive, clone the three module repositories into `modules/` at the
pinned commits instead. The full pipeline is long-running and memory-hungry.

## Data sources and licences

The runs use public datasets, mainly federal layers (ECCC, NRCan; Open Government Licence – Canada) and
territorial layers (GNWT; Open Government Licence – Northwest Territories). Sources are listed in
`data/core_manifest.csv` and `data/download_links.csv`. Only small spatial files are committed here
(`data/study_area/`, `data/testing/`); they are derived from such public datasets, and the original
licence terms and attribution requirements apply. Four Google Drive links in the manifests
(`NT_FORCOV.zip`, `Digaa_LandUsePermitArea.zip`, `Timberworks_LandUsePermitArea.zip`,
`CutblocksHistory_UpdatedJan2022.zip`) are access-restricted; obtain those layers from the original providers.
